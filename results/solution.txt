РАСПРЕДЕЛЕНИЕ ТРАФИКА ПО ДВУМ КАНАЛАМ

Максимизировать F = 3*x + 2*y
Ограничения: x + y <= 12; 2*x + y <= 18; x >= 0; y >= 0

Допустимые вершины:
   Канал А (x)    Канал Б (y)     Эффект F
             0              0            0
             0             12           24
             6              6           30
             9              0           27

ОПТИМАЛЬНОЕ РЕШЕНИЕ
Трафик по каналу А: 6
Трафик по каналу Б: 6
Максимальный полезный эффект: 30

Проверка ресурсов:
Физические линки: использовано 12 из 12; остаток 0
Маршрутизатор: использовано 18 из 18; остаток 0

Доказательство: (x + y) + (2*x + y) <= 12 + 18, то есть F <= 30.
В найденной точке F = 30. Верхняя граница достигнута.
