# Распределение трафика по двум каналам

Практическое задание по дисциплине «Методы оптимизации».

Программа решает задачу линейного программирования методом перебора вершин допустимой области. Оптимальное распределение: **6 единиц трафика по каналу А и 6 по каналу Б**, максимальный полезный эффект — **30**.

![Допустимая область и оптимальное решение](results/feasible_region.png)

Полное решение, математическая модель и объяснение алгоритма: **[REPORT.md](REPORT.md)**.

## Запуск в PyCharm

1. Распакуйте архив. Откройте в PyCharm папку `traffic_optimization`, в которой находится `main.py`.
2. Выберите интерпретатор Python 3.10 или новее. Можно использовать виртуальное окружение `.venv`, создаваемое PyCharm. Проверка проекта выполнена на Python 3.12.14 с Matplotlib 3.10.8; другие версии отдельно не проверялись.
3. Откройте вкладку **Terminal** внизу PyCharm. Убедитесь, что терминал находится в папке проекта.
4. Установите зависимость:

   ```bash
   python -m pip install -r requirements.txt
   ```

5. Запустите программу:

   ```bash
   python main.py
   ```

Также можно нажать правой кнопкой мыши на `main.py` и выбрать **Run 'main'**. Интерпретатор запуска и интерпретатор терминала должны совпадать.

Программа не запрашивает ввод: исходные данные задания уже заданы в коде. В консоли появятся вершины, оптимум и проверка ресурсов. В папке `results` создаются или обновляются текстовый результат и PNG-график. График не открывается в отдельном окне — его можно открыть в PyCharm или обычной программе просмотра изображений.

Папка результатов определяется относительно `main.py`, поэтому запуск из другой рабочей папки не меняет место сохранения.

### Расчёт без установки библиотек

```bash
python main.py --no-plot
```

Для вычислений достаточно стандартной библиотеки Python. Этот режим сохраняет `solution.txt`, но не создаёт и не обновляет рисунок. Готовый PNG уже включён в проект.

### Проверка правильности

```bash
python -m unittest -v
```

Ожидаемый итог: `Ran 6 tests` и `OK`. Проверяются вершины, оптимум, соблюдение каждого ограничения, дробные значения, параллельные и совпадающие прямые.

## Если запуск не удался

| Ситуация | Что проверить |
|---|---|
| Не установлен Matplotlib | Выполнить `python -m pip install -r requirements.txt` в окружении проекта |
| Установка прошла, а PyCharm не видит библиотеку | Сравнить путь из `python -c "import sys; print(sys.executable)"` с выбранным интерпретатором PyCharm |
| Не найден `main.py` или `requirements.txt` | Перейти в папку распакованного проекта |
| Нет прав на сохранение | Переместить проект в доступную для записи папку пользователя |
| Нечитаемая кириллица в терминале | Запустить `python -X utf8 main.py`; исходники и результат сохранены в UTF-8 |

Если график не удалось построить, программа сообщает об ошибке и возвращает ненулевой код завершения. Расчёт при этом уже выведен в консоль и, если доступна запись, сохранён в `solution.txt`.

## Загрузка на GitHub

Загрузите **содержимое** папки проекта, сохранив подпапку `results`. Тогда GitHub покажет этот README, график и отчёт с формулами. Одного ZIP-файла для удобного просмотра недостаточно — его нужно распаковать.

Не загружайте `.venv`, `.idea` и `__pycache__`. Они перечислены в `.gitignore`; при загрузке через браузер не выбирайте их вручную. Готовые `results/feasible_region.png` и `results/solution.txt` загружать нужно.

## Коротко для защиты

Обозначаем трафик по каналам через x и y. Максимизируем 3x + 2y при ограничениях на линки и маршрутизатор. Находим пересечения границ, оставляем допустимые точки и сравниваем эффект в вершинах. Лучший результат — (6; 6), эффект 30. Складывая ограничения, получаем 3x + 2y ≤ 30, поэтому лучшее значение действительно найдено.
